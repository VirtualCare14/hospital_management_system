## Branching & Pull Request Rules
1. **NEVER push directly to `main`**:
   - Pushing directly to `main` is strictly prohibited.
2. **Always create a branch**:
   - Before making or committing changes, ensure a separate branch is created from latest `origin/main` (e.g., `feat/<feature-name>`, `fix/<bug-name>`, or `ravi_dev`).
3. **Push to feature branch**:
   - Always push commits to the feature branch: `git push -u origin <branch-name>`.
4. **Merge via Pull Request**:
   - The repository maintainers review and merge the feature branch into `main`.
